
# E-Commerce Sales Analytics Dashboard

A Power BI-based analytics project focused on understanding e-commerce sales performance, product trends, order behavior, and delivery outcomes. This repository contains sample sales data and a dashboard designed to visualize key business metrics for decision-making.

## Overview

This project helps analyze:
- Sales performance over time
- Product-wise revenue and quantity sold
- Customer and order trends
- Product category trends
- Order status and delivery performance
- Dashboard-ready business insights for reporting

The project uses CSV datasets and a Power BI dashboard to present the analysis in a clear, business-friendly format.
